# dsh-ssh-ops 工程路线图

## 当前优化

- SSH 命令在收到结果前断线时报告执行结果未知。网络设备通过事前探测选择执行通道。
- 「导入」提供加密备份和 OpenSSH 配置两个入口。备份导入前预览数量和疑似重复项，可跳过重复服务器。OpenSSH 导入显示凭据与跳板提示，并逐条报告失败原因。
- SSH 资源支持按名称、地址、用户名或分组搜索，在线状态单独刷新。
- 流式下载与续传显示已校验字节数和总大小，校验期间可以取消。

## 已验证

- 用户在真实 Windows OpenSSH 环境验证了回收站和文件操作，确认正常。

- 2026-11-13，用户在 DSH Desktop 界面实测导入入口和终端分栏，确认操作正常。
- DSH Desktop 0.2.2-rc.2 隔离宿主通过 OpenSSH 导入、加密备份预览与恢复、跳板连接、两个独立 PTY 会话及 SFTP 列表和下载。隔离 Web Profile 已验证重启后导入资源保留。
- 在本机回环链路将下行限速至 4 MiB/s 后，通过跳板下载 16 MiB 文件。首次下载与从 8 MiB 处续传均通过 SHA-256 校验。两次收到响应头前均等待约 5.4 秒，随后下载分别耗时约 5.3 秒和 2.6 秒。保留全文件校验和等待状态提示。

- 后续改动涉及宿主入口或终端面板时，优先将可独立验证的职责抽出。
