# 可靠性与文件操作计划

1. 基线（已完成）：保留现有工作区改动并运行现有测试。
2. 下载（已实现，待 Desktop 验收）：支持文件保存 API 的浏览器可流式下载、校验并自动续传。用户可勾选跨重启续传，未完成数据以明文留在浏览器私有存储；每 4 MiB 写入一个检查点，重新连接相同服务器后可选择位置续传或清理。异常退出可能损失最近一个检查点以内的进度，浏览器也可能清理其存储。续传前重算远端 SHA-256，最终验证完整暂存文件后才提交目标。其他浏览器使用原有大小受限的下载方式。
3. 文件编辑（已实现，待验收）：修改前后并排预览并高亮变化区域；保存前核对原始字节、在原目录创建仅所有者可读写的备份。面板提供最近一次恢复入口，重新打开面板后也可从文件列表选择备份并恢复；恢复时再次备份当前文件。SFTP 不提供原子比较并写入，最后一次核对后仍有并发修改窗口。备份可能包含敏感配置，可在文件列表中按需删除。
4. 验收（部分完成）：204 项自动测试、构建、静态检查、npm 审计和打包清单检查通过；构建后的宿主在本地隔离 SSH/SFTP 服务上验证通过。Desktop 可加载插件面板，但测试时界面切换到已有服务器，未继续操作；新增下载、暂存和恢复的 Desktop 实机交互仍未验证。外部服务器和网络设备未测试。

真实环境验收清单：安装与升级；登录和指纹；文件传输与取消；断线及重连；审批通过、拒绝及断线；跳板与多窗格；网络设备提示符及分页。验收使用明确指定的测试目标，避免改变生产服务。

后续按需评估生产环境标识、健康检查、回收站界面和批量任务汇总。真实服务器上的变更需明确目标后进行。
