非常感谢这份清单，质量很高——**七条全部可行，这个版本落地了六条**，第 6 条单独说明。

**1. Ctrl+滚轮调整字号 ✅**
`Ctrl + 滚轮` 缩放字号（8–28），触控板**捏合手势**同样生效（浏览器里捏合就是带 Ctrl 的滚轮事件）。所有已开终端同步缩放，PTY 列数随之重算，字号偏好会记住，重开还在。

**2. 日志高亮 ✅**
落在「日志」页签的会话查看器：error / fatal / failed / traceback / `*Exception` / `EACCES` 这类 errno 行着**红**，warning / deprecated 行着**琥珀**，搜索命中行同色。没做在实时终端流上是刻意的——终端里远端程序本来就输出 ANSI 颜色，插件再叠加一层会打架，而且逐块扫描实时流有跨行边界的复杂度；日志查看器拿到的是已剥转义的整段文本，做行级着色最干净。

**3. 默认用户名 ✅**
做成了**自动记住**：新建服务器表单预填你**最近一次保存服务器所用的用户名**，不手动改就一直沿用，没有任何需要配置的地方（无历史时回落 `root`）。只影响新建表单，已保存的服务器不受影响。

**4. ssh_read 上下文减负 ✅（比建议的做法再进一步）**
你的诊断完全正确——旧版每次 ssh_read 把会话的 128KB 滚动缓冲整段吐出、读后不清，历史被反复重读。这版改成**默认增量读**：每次只返回上次读取之后新到的输出，旧结果不重复付上下文。没有做成「只读最近一条命令」是因为它依赖 shell 集成（OSC 133）开启才有命令边界，而增量读不依赖任何标记、对手动终端和交互程序场景同样成立；另外保留了 `mode: "tail"` 读全量，需要回看旧输出时用。

**5. 选中即复制 ✅**
划选文字松手后约 0.2 秒自动进剪贴板；清空选区的点击不会误覆盖剪贴板。

**7. ssh_exec 描述引导 ✅**
描述里已明确：切换用户（`sudo -i` / `su`）、进入容器（`docker exec -it`）、连接其他机器（`ssh`）这类需要终端交互的任务，改用 `ssh_write` 在交互终端完成。

**6. 危险命令接入原生 askuser ✅（v0.4.0 已落地）**
核实过宿主通道后，这一条在本版就做了，而且比「可选增强」更进一步——**整体替换**了原来的面板确认卡片：现在 agent 撞上危险命令，整个调用会在会话里挂起，由宿主的原生审批通道向你弹出确认（完整命令、所在主机、风险类别）。等待期间 agent 无法重试、换写法绕行或并行推进其它操作；人不在场时按拒绝处理（fail-closed，宁拒不误放）。批准一次性生效、只对刚才那条命令和那台机器有效，用完即焚——不存在「过期的卡片被误批」。批准简单 `rm` 时实际执行的依然是进回收站的可逆移动，误删照样能恢复。
