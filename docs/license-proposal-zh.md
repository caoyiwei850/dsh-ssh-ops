- 允许个人和企业免费安装、运行、修改本插件，供其自身内部运维使用，包括营利性企业的内部业务。

- 有意采用上述收费方式的，可以联系权利人商议单独授权。

## 待确认的条款边界

1. 明确“作为收费服务的一部分”是否包括服务提供商仅在自己的环境内部使用本插件为客户提供运维服务，而客户既不取得插件副本，也不能访问插件功能。
2. 明确免费插件与收费产品同时提供、但插件可独立免费获得时，是否属于禁止范围。
3. 明确插件修改版的免费分发条件，以及保留声明、标识修改和商业授权联系人等要求。
4. 请熟悉适用法律的软件许可律师起草或审阅正式中英文条款，避免禁止范围与允许企业内部运维的范围互相冲突。

- 已按 MIT 许可发布的旧版本及已获授权的代码，不能因未来版本改变许可而撤销其既有授权。
